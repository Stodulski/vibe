# This host serves no public pages. Storefronts, the booking flow and the city
# hubs live on vibe.com.ar, and this host has no sitemap of its own.
#
# Crawling is open on purpose, including for the pages that must NOT be indexed.
# Disallow and noindex are not the same thing: Disallow blocks the fetch, so a
# crawler never reads the noindex and keeps the URL in the index forever with no
# content behind it. That is exactly what happened to /login and /register,
# which were listed as Disallow and were indexed anyway, ranking for brand queries.
#
# So the rule is inverted: everything is crawlable, and vercel.json sends
# `X-Robots-Tag: noindex` on every path. Once a crawler refetches a URL it reads
# that header and drops the URL.

User-agent: *
Allow: /
