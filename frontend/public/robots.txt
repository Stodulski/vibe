# Crawling is open on purpose, including the pages that must NOT be indexed.
# Disallow and noindex are not the same thing: Disallow blocks the fetch, so a
# crawler never reads the noindex and keeps the URL in the index forever with no
# content behind it. That is exactly what happened here — /login and /register
# were listed as Disallow and were indexed anyway, ranking for brand queries.
#
# So the rule is inverted: everything is crawlable, and vercel.json sends
# `X-Robots-Tag: noindex` on every route that is not a complex's public page.
# Once Google refetches these URLs it reads that header and drops them.
#
# The only surface meant to be indexed on this host is /<slug>, the public page
# of each complex.

User-agent: *
Allow: /

# This host's own sitemap, listing every active complex's /<slug> page. It is
# generated by the backend at api.vibe.com.ar/api/sitemap.xml; vercel.json
# rewrites /sitemap.xml onto it so the URL sits on the same origin as the pages
# it lists, which is what Search Console requires without a cross-domain
# verification.
#
# The landing (vibe.com.ar) keeps its own sitemap for its own pages.
Sitemap: https://app.vibe.com.ar/sitemap.xml
